One theme, several publishing surfaces #

The example site is the manual. It demonstrates the same layouts and components you use from Markdown, without copying presentation markup into content.

Documentation
Navigation · search · table of contents
Write ordered technical guides with ordinary Markdown.
Publishing
Blog · articles · changelog
Publish long-form thinking and versioned release notes.
Product UI
Panels · metrics · status · fields
Compose branded application examples from reusable shortcodes.

Start from content #

Install the theme
Use a Hugo Module or git submodule.
Configure the site
Set menus, search output, syntax highlighting, and optional comments.
Write Markdown
Choose a section layout and add shortcodes only where a semantic component is needed.

Brand contract

Cloud · Agile · Agentic AI. Direct, technical, humanistic, and restrained. The theme carries the current v2.1.1 tokens so content authors do not need to recreate the design system page by page.
