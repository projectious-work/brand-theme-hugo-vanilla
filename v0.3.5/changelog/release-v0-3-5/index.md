# v0.3.5 — readable dark selections and solid navigation

> Dark surfaces now use accessible selection colors, and the sticky header remains visually separate from scrolling content.


v0.3.5 makes dark-mode reading and navigation clearer.

## Accessible text selection

Deep-dark and navy-dark surfaces now select text with a high-contrast navy
background and light foreground instead of the previous brown-and-dark pairing.
Browser coverage verifies the contrast in desktop and mobile layouts.

## Solid sticky header

The sticky header now uses a fully opaque theme surface. Page content can no
longer show through beneath its navigation, search, version, language, and
accessibility controls while scrolling.
