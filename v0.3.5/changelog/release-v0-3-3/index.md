# v0.3.3 — consolidated features and versatile examples

> Feature documentation now covers every public shortcode, while new full-page examples demonstrate the theme beyond documentation sites.


v0.3.3 makes the theme easier to evaluate, learn and adapt without changing its
existing public contracts.

## Complete feature documentation

The former Shortcodes section is now part of the authoritative
[Features](../../docs/features/) section. Every public content component has a
focused page with a rendered result and copyable source. The same structure is
available in English, German and French.

## Versatile page examples

The [Examples](../../docs/examples/) section now includes theme-native
administration, dashboard, settings, pricing, run-state, article and change-log
compositions. Operational examples use full-screen application shells to show
how the design system works beyond the documentation layout.

## Navigation and release history

Sidebar groups default to closed, preserve reader state and provide a compact
expand-all/collapse-all control. The former Blog has become this chronological
Change log. Legacy links continue to redirect to their new locations.

Download the archive and checksum from the
[v0.3.3 GitHub Release](https://github.com/projectious-work/brand-theme-hugo-vanilla/releases/tag/v0.3.3).
