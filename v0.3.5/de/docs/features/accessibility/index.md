# Barrierefreiheit

> Tastaturbedienung, Leserpräferenzen und Pflichten für Autoren.


Das Theme bietet Sprunglink, sichtbaren Fokus, semantische Bereiche, skalierbare
Schrift, reduzierte Bewegung und kontrastreiche Bedienelemente. Das Menü speichert
Textgröße, hohen Kontrast, einen besonders starken Drei-Pixel-Fokusring,
Link-Unterstreichung, reduzierte Bewegung und Textabstände lokal.

Autoren benötigen sinnvolle Alternativtexte, geordnete Überschriften und Labels
für alleinstehende Symbole.
