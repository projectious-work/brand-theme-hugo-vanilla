# Konfiguration

> Website-weite Einstellungen und Frontmatter einzelner Seiten.


[Website-weite Konfiguration](site-wide.md) beschreibt `hugo.toml`, Module,
Ausgaben und Theme-Parameter. Die
[Seitenkonfiguration (Frontmatter)](page-configuration.md) gilt jeweils für eine
Markdown-Datei oder einen Bereich.


- [Website-weite Konfiguration](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/de/docs/configuration/site-wide/index.md) — Hugo, Ausgaben, Menüs, Sprachen und Theme-Parameter konfigurieren.
- [Seitenkonfiguration (Frontmatter)](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/de/docs/configuration/page-configuration/index.md) — Navigation und optionale Funktionen einer Seite steuern.
