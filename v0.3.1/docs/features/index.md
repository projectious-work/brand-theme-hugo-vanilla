# Features

> A complete map of reader, author and maintainer capabilities.


The cards below provide a complete map of the theme's reader, author and
maintainer capabilities, with configuration and usage instructions for each
feature. The visual language and tokens come from the
[projectious.work brand design system](https://github.com/projectious-work/brand).

For an end-to-end workflow, continue with the
[content authoring guide](../guides/_index.md), the
[shortcode reference](../shortcodes.md), and the
[maintenance guide](../maintenance.md).


- [Versioned documentation](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/versioning/index.md) — Publish separate documentation builds and connect them with the version menu.
- [Tokens and public API](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/tokens/index.md) — Inspect the stable semantic CSS tokens and Tailwind namespaces generated from the theme source.
- [Terminal recordings](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/terminal-recordings/index.md) — Record and embed copyable terminal sessions with asciinema.
- [Tailwind and design tokens](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/tailwind/index.md) — Use the theme's Tailwind integration and stable projectious.work design tokens.
- [Tags](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/tags/index.md) — Use Hugo taxonomies for related-content and release-note metadata.
- [Search](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/search/index.md) — How the generated search index, header search and command palette work.
- [Mathematics](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/mathematics/index.md) — Render inline and display mathematics with KaTeX.
- [Jupyter notebooks](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/jupyter-notebooks/index.md) — Convert and publish reproducible notebook output.
- [Internationalization](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/internationalization/index.md) — Configure translated content, language navigation, metadata and RTL layout.
- [Header and navigation](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/header-navigation/index.md) — Configure primary links, repository actions, search and header controls.
- [Editing and feedback](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/editing-feedback/index.md) — Connect pages to their source files and optionally collect useful reader votes.
- [Diagrams](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/diagrams/index.md) — Render responsive Mermaid diagrams from Markdown.
- [Code blocks](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/code-blocks/index.md) — Configure syntax highlighting, filenames, line numbers, highlighted lines and linkable anchors.
- [Accessibility](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.1/docs/features/accessibility/index.md) — Keyboard behavior, reader preferences and author responsibilities.
