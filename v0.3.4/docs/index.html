Documentation

Install, configure, author, extend and maintain the projectious.work Hugo theme.

Begin with Getting started, then configure the site before writing content. The feature map explains reader-facing capabilities; Guides is the authoritative authoring walkthrough; the developer and maintenance pages cover adaptation and upgrades.

Getting started

Create a Hugo site from scratch, install the theme from a release or local checkout, configure its outputs and run it.
