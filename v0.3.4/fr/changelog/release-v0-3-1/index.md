# v0.3.1 — design révisé et documentation complète du thème

> Le design finalisé, des diagrammes fiables et une documentation multilingue complète arrivent dans cette version corrective.


v0.3.1 fournit l'implémentation finalisée du thème après la publication
initiale de v0.3.0.

## Système de design

Les couleurs, la typographie, les élévations, le focus et les alignements
suivent désormais le système de design projectious.work révisé. Les panneaux de
code et de terminal sont adaptatifs et distincts, avec tous les rôles de syntaxe
et les palettes de terminal de la marque.

## Documentation

Les sites anglais, allemand et français expliquent l'installation, la
configuration, la création de contenu et de modèles, la maintenance, les
dépendances et l'API publique du thème.

## Corrections

- Les diagrammes Mermaid sont rendus et dimensionnés de façon fiable.
- La barre latérale et la table des matières conservent leurs états séparés.
- Les liens préservent langues, chemins de base, requêtes et fragments.
- Les fonctionnalités sont classées par ordre alphabétique.

L'archive et sa somme de contrôle sont disponibles dans la
[version GitHub v0.3.1](https://github.com/projectious-work/brand-theme-hugo-vanilla/releases/tag/v0.3.1).
