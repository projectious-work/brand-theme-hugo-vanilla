# Configuration

> Configure the whole site and control individual pages through front matter.


Configuration has two scopes. Start with
[Site-wide configuration](site-wide.md) for `hugo.toml`, modules, outputs,
menus, languages and theme parameters. Use
[Page configuration (front matter)](page-configuration.md) for settings that
belong to one content file or section.

Site creators normally configure both scopes; content authors usually need only
front matter after the site has been set up.


- [Site-wide configuration](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/docs/configuration/site-wide/index.md) — Configure Hugo, outputs, Markdown, menus, languages and theme parameters.
- [Page configuration (front matter)](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/docs/configuration/page-configuration/index.md) — Control navigation, cards, tables of contents and optional page capabilities.
