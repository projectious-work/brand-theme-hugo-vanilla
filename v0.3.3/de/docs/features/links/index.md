# Links

> Basispfad-sichere Verweise innerhalb und zwischen Hugo-Seiten.


```md
[Konfiguration](../configuration/_index.md)
[Ausgabeformate](../configuration/site-wide.md#ausgabeformate)
[Abschnitt auf dieser Seite](#links)
```

Inhaltsbezogene Pfade lassen den Build fehlschlagen, wenn das Ziel verschoben
wurde. Externe Links erhalten automatisch sichere Attribute und ein Icon.
