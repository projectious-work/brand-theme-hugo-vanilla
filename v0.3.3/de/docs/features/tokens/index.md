# Tokens und öffentliche API

> Stabile semantische CSS-Tokens und Tailwind-Namensräume aus dem Theme-Quelltext.


Die Tabellen werden während des Hugo-Builds direkt aus dem CSS des Themes
erzeugt. Eigene Templates sollten semantische Tokens und dokumentierte
Tailwind-Namensräume verwenden, nicht interne Palettenstufen oder Selektoren.
