# Change log

> Theme releases and the changes delivered in each version.



- [v0.3.3 — consolidated features and versatile examples](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/changelog/release-v0-3-3/index.md) — Feature documentation now covers every public shortcode, while new full-page examples demonstrate the theme beyond documentation sites.
- [v0.3.2 — public hooks for site-owned assets](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/changelog/release-v0-3-2/index.md) — Consuming sites can now append Hugo-piped CSS and JavaScript without replacing the theme's internal pipelines.
- [v0.3.1 — revised design system and complete theme guidance](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/changelog/release-v0-3-1/index.md) — The finalized design system, reliable diagrams and comprehensive multilingual guidance arrive in this patch release.
- [v0.3.0 — pinned runtimes, section-filtered search, command palette](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/changelog/release-v0-3-0/index.md) — Runtime assets are version-pinned, search indexes headings, and every page action sits in one row.
- [v0.2.0 — navy dark mode and the accessibility layer](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.3/changelog/release-v0-2-0/index.md) — Dark mode moves onto the midnight scale, and every accessibility setting became opt-in.
