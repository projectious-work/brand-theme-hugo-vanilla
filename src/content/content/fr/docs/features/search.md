Hugo génère `/index.json` avec titres, descriptions, tags, contenu et titres H2/H3.
FlexSearch fonctionne localement dans le navigateur. `/` place le curseur dans la
recherche; `Ctrl`/`Cmd`+`K` ouvre la palette. Activez `SearchIndex` dans
`outputs.home`; `params.search = false` désactive la fonction.
