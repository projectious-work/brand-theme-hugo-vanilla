Configuration has two scopes. Start with
[Site-wide configuration](site-wide.md) for `hugo.toml`, modules, outputs,
menus, languages and theme parameters. Use
[Page configuration (front matter)](page-configuration.md) for settings that
belong to one content file or section.

Site creators normally configure both scopes; content authors usually need only
front matter after the site has been set up.
