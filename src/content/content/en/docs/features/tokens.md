The tables below are generated from the theme's CSS during the Hugo build. Use
semantic tokens and documented Tailwind namespaces in site-owned templates;
palette steps, component selectors and internal behavior attributes may change.

The root `API.md` defines the complete compatibility contract. For practical
authoring examples, see [Tailwind and design tokens](tailwind.md).
