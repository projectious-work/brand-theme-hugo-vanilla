The theme combines Hugo-native content organization with progressive enhancement.
Use this overview to find the configuration and authoring instructions for each
capability. Visual language and tokens come from the
[projectious.work brand design system](https://github.com/projectious-work/brand).

## Reading and navigation

- Generated hierarchical sidebar, breadcrumbs and previous/next links
- Active-heading table of contents and mobile table of contents
- Responsive header, sidebar drawer and command palette
- Whole-section print view and per-page Markdown output
- Light, navy and deep-dark appearances

See [Header and navigation](header-navigation.md) and
[Accessibility](accessibility.md), [Editing and feedback](editing-feedback.md) and
[Tailwind and design tokens](tailwind.md).

## Discovery and publishing

- Local full-text and heading search
- Hugo taxonomies and tags
- Styled RSS, canonical URLs, sitemap and `hreflang`
- `/llms.txt` and Markdown representations for machine readers
- Release-note blog and documentation version selector

See [Search](search.md), [Tags](tags.md) and [Versioned documentation](versioning.md).

## Authoring

- Generated child-page cards from front matter
- Syntax-highlighted code with filenames, line numbers and copy buttons
- Callouts, tabs, steps, details, file trees and buttons
- Mermaid diagrams, KaTeX mathematics, asciinema terminal recordings
- Pre-converted Jupyter notebook output and responsive images

Continue with the [content authoring guide](../guides/_index.md) and
[Code blocks](code-blocks.md), then use the [shortcode reference](../shortcodes.md)
for richer components.

## Operations

- Multilingual content, translated metadata and right-to-left layout
- Pinned third-party runtime versions with an optional self-hosted mode
- Deterministic two-pass builds and browser visual regression tests
- Local-only release and GitHub Pages deployment scripts

See [Internationalization](internationalization.md),
[Maintenance](../maintenance.md) and [Dependencies and SBOM](../dependencies.md).
