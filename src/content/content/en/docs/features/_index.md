The cards below provide a complete map of the theme's reader, author and
maintainer capabilities, with rendered examples and copyable Markdown for each
feature. The visual language and tokens come from the
[projectious.work brand design system](https://github.com/projectious-work/brand).

For an end-to-end workflow, continue with the
[content authoring guide](../guides/_index.md) and the
[maintenance guide](../maintenance.md).

## Shortcode syntax

A shortcode whose template reads inner content needs a closing tag. Use the
Markdown-rendering `%` delimiter for a body of prose, and the `<` delimiter when
nesting another shortcode so its HTML is not escaped. Unpaired shortcodes have no
closing tag and must not use an XML-style trailing slash.

Every shortcode shipped by the theme is documented in the feature cards below.
