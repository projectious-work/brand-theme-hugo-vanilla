# Contributing

`main` remains the stable v0.2.x line. The `release/v0.3.0` branch is the
explicitly approved integration branch for the next major implementation.

Until the v0.3.0 architecture and verification commands are established:

- make v0.3.0 work on short-lived branches based on `release/v0.3.0`;
- merge reviewed changes back into `release/v0.3.0`;
- use Conventional Commits;
- do not edit the generated `gh-pages` branch directly; and
- do not recreate or copy the removed v0.2.x Hugo implementation implicitly.

The immutable `v0.2.x` tags remain the reference for the previous theme.
