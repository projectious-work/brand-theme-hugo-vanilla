# brand-theme-hugo-vanilla

The `release/v0.3.0` branch is an intentionally clean foundation for the next
major iteration.

The previous Hugo theme implementation, example site, generated artifacts,
theme-specific tests, build scripts, deployment scripts, and product MCP were
removed from this branch. The released `v0.2.x` source remains available from
its immutable Git tags, and the published site remains on the `gh-pages`
branch.

No v0.3.0 implementation has been added yet.
