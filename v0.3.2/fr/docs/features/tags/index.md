# Tags

> Taxonomies Hugo pour les métadonnées et les contenus associés.


Ajoutez `tags = ["release", "accessibilité"]` au front matter. Le thème affiche
les tags dans les métadonnées, les indexe et génère les pages de taxonomie. Le site
d'exemple ne place volontairement pas Tags dans la navigation principale.
