# Documentation

> Install, configure, author, extend and maintain the projectious.work Hugo theme.


Begin with **Getting started**, then configure the site before writing content.
The feature map explains reader-facing capabilities; Guides is the authoritative
authoring walkthrough; the developer and maintenance pages cover adaptation and
upgrades.


- [Getting started](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/getting-started/index.md) — Create a Hugo site from scratch, install the theme from a release or local checkout, configure its outputs and run it.
- [Configuration](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/configuration/index.md) — Configure the whole site and control individual pages through front matter.
- [Features](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/features/index.md) — A complete map of reader, author and maintainer capabilities.
- [Guides](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/guides/index.md) — Write pages, links, code, diagrams, recordings and notebook output with Hugo-friendly Markdown.
- [Shortcodes](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/shortcodes/index.md) — Every component the theme ships, with the Markdown that produces it.
- [Developer guide](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/developer-guide/index.md) — Adapt the theme, swap bundled assets, run tests and contribute changes safely.
- [Maintenance and upgrades](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/maintenance/index.md) — Keep the theme, runtime pins, content and published documentation current.
- [Dependencies and SBOM](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.2/docs/dependencies/index.md) — Understand build tools, browser runtimes, bundled assets, versions and licences.
