# v0.3.1 — revised design system and complete theme guidance

> The finalized design system, reliable diagrams and comprehensive multilingual guidance arrive in this patch release.


v0.3.1 delivers the finalized theme implementation that followed the original
v0.3.0 publication.

## Design-system integration

The theme now follows the revised projectious.work colour, typography,
elevation, focus and alignment contracts. Code and terminal panels have
separate adaptive surfaces, complete syntax weights and italics, readable text
selection and branded terminal-recording palettes.

## Documentation

English, German and French sites now explain installation from scratch,
site-wide and page configuration, content and template authoring, maintenance,
dependencies and the public theme API. Feature pages cover accessibility, code,
diagrams, editing, navigation, internationalization, notebooks, mathematics,
search, tags, Tailwind, recordings, tokens and versioning.

## Reliability fixes

- Mermaid diagrams render consistently and scale to their content.
- Sidebar and table-of-contents highlighting remain independent while scrolling.
- Links retain language prefixes, project base paths, queries and fragments.
- Strong focus rings, token swatches, lists, file trees and print output use the
  intended design tokens.
- Feature navigation and overview cards are alphabetized in each language.
