# Über

> Was dieses Theme ist und was es bewusst weglässt.


Das Theme setzt das projectious.work Markensystem für Hugo um: drei Schriftrollen,
ein Drei-Farben-Kern, zwölfstufige Skalen in beiden Modi und die im Markensystem
dokumentierten Komponentenrezepte. Kein Analytics, kein JS-Framework, kein
Icon-CDN — der Icon-Satz liegt im Repository und wird inline eingebettet.
