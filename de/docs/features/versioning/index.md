# Versionierte Dokumentation

> Getrennte Builds veröffentlichen und über das Versionsmenü verbinden.


Jede Version ist ein eigener Hugo-Build. Die aktuelle Dokumentation bleibt am
stabilen Root, ältere Versionen liegen beispielsweise unter `/v0.2/`. Tragen Sie
nur bereits veröffentlichte URLs in `params.versions` ein. Mit `probe = false`
landet ein Eintrag auf der Versionsstartseite statt beim gleichen Seitenpfad.
