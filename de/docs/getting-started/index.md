# Erste Schritte

> Theme als Hugo-Modul einbinden und die erste Seite bauen.


## Voraussetzungen

Hugo **0.128.0** oder neuer, Go für die Modulauflösung, Node nur für den
Tailwind-Schritt.

{{< terminal >}}
$ npm install
$ hugo server
{{< /terminal >}}
