> Release Notes zum Theme.



- [v0.3.2 — öffentliche Hooks für Website-Assets](https://projectious-work.github.io/brand-theme-hugo-vanilla/de/blog/release-v0-3-2/index.md) — Nutzende Websites können eigenes CSS und JavaScript über Hugo Pipes ergänzen, ohne interne Theme-Pipelines zu ersetzen.

- [v0.2.0 — Navy-Dunkelmodus und die Barrierefreiheits-Ebene](https://projectious-work.github.io/brand-theme-hugo-vanilla/de/blog/release-v0-2-0/index.md) — Der Dunkelmodus wechselt auf die Midnight-Skala, und alle Einstellungen sind opt-in.
