Theme contract reference

This reference is rendered from src/data/product_contract.json, the normative machine-readable contract released with the theme. Tutorials and examples explain techniques; this page defines the supported public interface.

Compatibility

Minimum Hugo0.121.0
Tested Hugo0.164.0
Hugo Extendedtrue

Configuration

Ignored by Hugo but unsupported by this theme contract.

PathTypeDefaultEffect
params.descriptionstringsite titleFallback SEO and search description.
params.fontsenumbundledSelects pinned local WOFF2 or platform font stacks.
params.search.placementenumheaderControls header search visibility.
params.giscus.repostringEnables giscus when repo IDs are also supplied.
params.giscus.repoIdstringGiscus repository identifier.
params.giscus.categoryIdstringGiscus category identifier.
params.socialarray[]Footer links with name and URL.
params.accessibility.autobooleantrueFollows operating-system accessibility preferences.
params.accessibility.focusstringstrongSelects the conforming focus-ring profile.
params.accessibility.linkUnderlinebooleanfalseOpt-in underlines for prose links; navigation chrome remains undecorated.
params.githubstringAdds an icon link to the repository between search and the theme switch.
