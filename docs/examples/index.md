# Examples

> Complete theme-native page compositions beyond documentation layouts.


Each example uses the theme's public tokens, typography, controls and Hugo
templates. Open a card to inspect a complete page without the documentation
sidebar or table of contents.


- [Admin page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/admin/index.md) — Member management, roles, status badges and a responsive data table.
- [Dashboard page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/dashboard/index.md) — Operational metrics, activity trends and current pipeline state.
- [Settings page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/settings/index.md) — Grouped form controls, validation, switches and save actions.
- [Pricing page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/pricing/index.md) — Three clear service tiers with one emphasized recommendation.
- [Run state page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/run-state/index.md) — Observability states for empty, loading, successful and failed runs.
- [Article page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/article/index.md) — A focused long-form article with metadata and a reading rail.
- [Changelog page](https://projectious-work.github.io/brand-theme-hugo-vanilla/docs/examples/changelog/index.md) — A chronological product history with compact semantic change labels.
