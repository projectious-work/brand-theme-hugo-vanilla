Diagrams

Render responsive Mermaid diagrams from Markdown.

Mermaid turns text definitions into diagrams. A mermaid fence or the paired shortcode loads the pinned runtime only on pages that need it and redraws the diagram after a colour-mode change.

flowchart LR
  M[Markdown] --> H[Hugo]
  H --> S[Search index]
  H --> P[HTML and print]
