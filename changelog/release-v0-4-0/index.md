# v0.4.0 — data-driven components and integrated graphics

> Author rich data components and diagrams from inline source, local files or approved URLs, with a refreshed project identity.


v0.4.0 turns diagrams, charts and structured data into first-class theme
content while keeping builds deterministic and authoring paths explicit.

## Data and graphics

Badges, card lists and data tables accept inline values, local files or approved
URLs. Tables can opt into search, sorting, filtering, column alignment and
type-aware formatting.

D2, Graphviz and Typst/CeTZ sources integrate with the Hugo build. Observable
Plot, JSXGraph, WaveDrom, SMILES Drawer and pseudocode.js add focused browser
renderers. The documentation includes complete source, data and rendered
examples, including network topology, provider-style infrastructure and useful
Typst graphics packages.

D2 and Graphviz output is inline SVG with selectable text. Typst output is also
inline SVG, although Typst deliberately converts glyphs to vector paths.

## Installation and identity

A new Installation guide separates mandatory prerequisites from optional
graphics tools and documents modules, local checkouts, offline builds and
verification. A complete new logo suite supplies readable light, dark,
monochrome, favicon and touch-icon variants through the existing brand settings.
