# v0.2.0 — navy dark mode and the accessibility layer

> Dark mode moves onto the midnight scale, and every accessibility setting became opt-in.


## Navy dark mode

Dark mode previously painted pages and cards on the terminal surface (`#0e1720`),
which read as near-black. Page and card surfaces now sit higher up the midnight
scale — `#132440` and `#1a2b3e` — while code panels stay on the terminal surface,
so a listing reads as recessed against the page around it.

The mode menu offers **Light**, **Dark navy**, **Dark deep** and **System**. System
dark resolves to navy.

## Accessibility selectors

Text size, high contrast, strong focus ring, link underlines, reduced motion and
loose text spacing are exposed in the header and persist per reader. Every setting
is opt-in: nothing changes until the reader asks for it.

## Fixes

- Accent text uses `orange-11` on tinted rows, clearing AA
- Card hover is a border and elevation shift, never an underline
- The wordmark centres optically against the mark
