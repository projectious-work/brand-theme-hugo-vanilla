# Configuration

> Réglages du site et front matter de chaque page.


La [Configuration globale du site](site-wide.md) décrit `hugo.toml`, les modules,
les sorties et les paramètres du thème. La
[Configuration de page (front matter)](page-configuration.md) concerne un fichier
Markdown ou une section.


- [Configuration globale du site](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.6/fr/docs/configuration/site-wide/index.md) — Configurer Hugo, les sorties, les menus, les langues et le thème.
- [Configuration de page (front matter)](https://projectious-work.github.io/brand-theme-hugo-vanilla/v0.3.6/fr/docs/configuration/page-configuration/index.md) — Contrôler la navigation et les fonctions propres à une page.
